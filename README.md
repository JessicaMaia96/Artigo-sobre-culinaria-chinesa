# 🥢 Blog de Culinária Chinesa

Um site estático desenvolvido com **HTML** e **CSS**, que apresenta a rica e milenar gastronomia chinesa.  
O projeto reúne pratos tradicionais, curiosidades culturais e informações sobre ingredientes e costumes da culinária da China.

## 🚀 Funcionalidades
- Página inicial com introdução à culinária chinesa
- Seções com pratos típicos (Pato à Pequim, Frango Kung Pao, Mapo Tofu, etc.)
- Área de curiosidades sobre tradições e costumes
- Vídeo explicativo sobre equilíbrio alimentar (Yin e Yang)
- Conteúdo adicional em **aside** com informações sobre ingredientes, mandamentos e comidas exóticas
- Rodapé com direitos autorais

## 📂 Estrutura do projeto
- `index.html` → página principal com todo o conteúdo
- `style.css` → estilos e layout do site
- `images/` → imagens dos pratos e curiosidades
- `media/` → vídeo e capa utilizados no projeto
